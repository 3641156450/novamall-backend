# 智联招聘投递素材包

智联的附件/作品只认**文本和图片**，这个目录就是为它准备的：文本直接复制粘贴，图片直接上传。

| 文件 | 用途 | 怎么用 |
|---|---|---|
| `01-项目经历-精简版.txt` | 简历「项目经历」栏 | 全选复制 → 粘贴到智联项目描述框（约 320 字，字数受限时用这个） |
| `02-专业技能-纯文本.txt` | 简历「专业技能」栏 | 全选复制粘贴 |
| `03-自我评价-纯文本.txt` | 简历「自我评价」栏 | 全选复制粘贴 |
| `images/00-作品说明完整长图.jpg` | 作品附件 | 上传，HR 打开就能看懂整个项目 |
| `images/01-项目总览与架构.jpg` | 作品附件 | 上传，讲技术栈和架构用 |
| `images/02-技术亮点与模块职责.jpg` | 作品附件 | 上传，讲六个技术亮点用 |
| `images/03-简历项目经历.jpg` | 作品附件 | 上传，一页看完项目经历 |

## 投递时的三个注意点

1. **先替换占位数字**：`01` 里 `[500] 并发` 这类带方括号的数字，要用你自己的压测结果替换
   （见 `docs/05-压测报告.md`）。没跑过压测就删掉数字，改成"本地验证功能正确，无超卖、无重复下单"。
2. **GitHub 链接要能打开**：仓库设为 public，`01` 里的 `github.com/3641156450/novamall-backend`
   换成你自己的用户名。智联简历里放仓库链接，比放"熟练掌握"四个字有用得多。
3. **图片别超过 5 张**：智联作品附件一般最多 5 个，建议传 `00`（完整长图）+ `03`（项目经历）就够了。
   面试时如果需要展开讲，再当场打开 `02`。
